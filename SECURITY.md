# Security policy

Pickosaurus is preparing its first release. There is currently no supported public
binary release; fixes are made on `main`. Review [the audit](SECURITY_AUDIT.md) and
[privacy notes](PRIVACY.md) before granting profile-automation permissions.

Use GitHub private vulnerability reporting when enabled for this repository. If
it is unavailable, ask the maintainer for a private reporting channel without
posting the vulnerability details publicly. Never include real meeting passcodes,
cookies, credentials or confidential links in an issue or reproducer.

Include the affected revision/build, macOS version, Basic/profile mode, minimal
reproduction steps using synthetic URLs, and the expected versus actual behavior.
Test only systems and accounts you own or have permission to test.
